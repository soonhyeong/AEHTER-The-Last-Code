# AETHER: The Last Code

AI가 지배하는 폐허 도시에서 두 생존자가 ‘마지막 코드’를 되찾기 위해 협력하는 **2인 협동 생존 액션 RPG** 프로젝트입니다.

## 게임 소개

포스트 아포칼립스 SF 세계를 배경으로, 플레이어는 환경을 탐색하고 자원을 수집하며 로봇과 맞섭니다. 전력 회로와 보안 시스템을 해결하고 강화 파츠를 제작·장착하면서 다음 구역으로 나아가는 게임을 목표로 개발했습니다.

## 주요 요소

- **탐험과 상호작용** — 주변 사물, 아이템, 문과 단말기를 조사하고 활용합니다.
- **전투와 생존** — 로봇 계열 적과 전투하며 플레이어 상태와 자원을 관리합니다.
- **퍼즐과 해킹** — 회로 연결과 코드 해독 등 구역별 퍼즐을 해결합니다.
- **강화 파츠** — 재료를 모아 파츠를 제작하고 장착해 이동·방어 능력을 활용합니다.
- **협동 플레이** — 두 플레이어가 함께 진행하는 플레이를 목표로 구성한 프로젝트입니다.

## 개발 정보

- 엔진: Unity 6000.2.12f1
- 언어: C#
- 목표 플랫폼: Windows PC
- 개발 형태: 4인 팀 프로젝트
